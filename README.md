# शुभ विवाह निमंत्रण – चि० धीरज संग आयु० कु० प्रिया

- `index.html` – निमंत्रण पत्र (3 पेज, A5). **Print** बटन दबाएँ → मेहमान का नाम लिखें → "Save as PDF" चुनें।
- `Shubh_Vivah_Nimantran.pdf` – बिना नाम वाला PDF (हाथ से नाम लिखने के लिए)।
- `bulk.html` – Bulk कार्ड: मेहमानों की सूची (नाम, गाँव, मोबाइल) डालें → हर मेहमान का अलग कार्ड (PDF/फ़ोटो) डाउनलोड करें, सभी का ZIP बनाएँ, या WhatsApp (मोबाइल ऐप / WhatsApp Web) से सीधे भेजें। कोई API नहीं — सिर्फ़ wa.me लिंक और फ़ोन का Share।
